Why 2.5D — not 2D or full 3D?
A judge-friendly explanation of the representation choice.
DESIGN RATIONALE

2D Occupancy

Compact X–Y occupancy, but elevation is lost. Slopes, curbs, road edges, object height and multi-level returns are poorly represented.

2.5D Elevation Grid ★

Keeps an X–Y spatial grid but stores elevation statistics in each cell. This captures terrain and obstacle height with much lower representation cost than full volumetric mapping.

Full 3D

Preserves complete vertical geometry, but occupied voxels or point storage can grow rapidly. FFEM uses 3D LiDAR observations while keeping the mapping representation compact and adaptive.
